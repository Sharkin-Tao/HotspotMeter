# 01 产品需求

优先级：**P0** = 第一版必须；**P1** = 第一版尽量；**P2** = 后续版本。

## 1. 功能需求

### FR-01 热点识别与选择（P0）

- 枚举本机 Wi-Fi 接口与当前连接信息（SSID、BSSID、接口 GUID）。
- 提供设置界面让用户**主动选择**要监控的热点；不得默认把所有 Wi-Fi 都当成热点。
- 目标热点用"接口 GUID + SSID + BSSID"组合标识，其中 **GUID 是主键**，SSID 仅显示；不能只凭 SSID 判断身份。
- 用户更换/USB 网卡后接口 GUID 会变，需要允许重新选择并保留历史数据。
- 验收：连学校 Wi-Fi 时不产生会话；连接选定热点后 10 秒内进入"已连接"状态。

### FR-02 实时流量采集（P0）

- 只读取目标 Wi-Fi 接口的累计收/发字节，采样间隔默认 1 秒。
- 下载 = 接收字节增量，上传 = 发送字节增量。
- 速度 = 增量 ÷ 实际经过时间（单调时钟），不做跨进程/跨重启的计数器差值。
- 必须处理：计数器回退（重新建基线，不产生负数）、接口变化（重新识别）、睡眠唤醒（重新建基线，不把休眠期间的长间隔算成流量）。
- 验收：播放一段已知大小的视频，10 分钟内累计值与系统"数据使用量"差值在一次采样量级内。

### FR-03 会话管理（P0）

- 目标热点连接成功 → 新建 Session；断开 → 结束 Session。
- Session 记录：SessionId、HotspotId、StartTime、EndTime、DownloadBytes、UploadBytes、SessionStatus。
- 同一会话内多次短暂掉线（比如 3 秒内重连）是否合并，作为**待确认策略**，默认按"每次连接新建会话"（与总指令一致）。
- 验收：连续断开重连 10 次，数据库出现 10 条会话，日汇总等于 10 条之和。

### FR-04 悬浮状态栏（P0）

- 独立无边框透明窗口，圆角胶囊，可拖动，可固定，位置记忆。
- 已连接：绿色背景、Wi-Fi 图标 + "已连接"、大字号当前会话流量、"已使用流量"小字、右下角实时 ↓/↑ 速度。
- 未连接：红色背景、Wi-Fi-off 图标 + "未连接"、保留上次会话流量并明确标注、速度为 0。
- 右键菜单：流量统计 / 设置 / 固定位置（或解除固定）/ 退出程序。
- 只显示连接状态、会话流量、实时速度；**禁止**任何日/周/月统计、图表、历史列表。
- 验收：拖动流畅；固定后不可拖动；重启程序后位置与固定状态保持；DPI 150% 下不模糊、不越界。

### FR-05 窗口定位（P1，允许降级）

- 启动时尽可能定位到任务栏开始按钮附近空位，且不遮挡开始按钮、搜索框、任务栏其他控件。
- 支持多显示器、任务栏在上下左右、DPI 变化、分辨率变化。
- 自动定位失败 → 使用上次位置或屏幕安全位置；用户可手动拖动并保存。
- **不允许**注入 Explorer、修改系统文件、使用未公开接口。
- 验收：在 100%/125%/150% 缩放下，窗口完整可见且不覆盖开始按钮；拔插显示器后 3 秒内回到可见区域。

### FR-06 独立流量统计窗口（P0）

- 正常带标题栏的桌面窗口，通过悬浮窗右键菜单打开；与悬浮窗完全独立。
- 内容：今日总/下载/上传、每日记录列表、每周统计、每月统计、历史日期查询、每日连接次数、每日连接时长。
- 关闭统计窗口**不退出程序**，后台监控与悬浮窗继续。
- 重复打开时激活已有窗口，不创建多个实例。
- 验收：关闭统计窗口后继续产生流量，重新打开数据连续。

### FR-07 数据持久化（P0）

- SQLite，表：HotspotProfiles、ConnectionSessions、TrafficSnapshots、DailyTraffic、AppSettings（+ 版本表）。
- 5–10 秒检查点；断开、退出、睡眠前立即落盘。
- 数据目录默认 `%LOCALAPPDATA%\HotspotMeter\`，不得写入程序安装目录（避免权限问题）。
- 验收：强制结束进程后重启，已提交检查点的数据不丢、不重复。

### FR-08 异常恢复（P0）

- 启动时发现未结束会话 → 用最后检查点收尾，标记为"已恢复/中断"。
- 网卡/系统重启后，绝不把新计数器原始值当作增量累加。
- `DailyTraffic` 可由 `ConnectionSessions` + `TrafficSnapshots` 重算，并提供内部修复入口。
- 验收：见 07 的场景矩阵。

### FR-09 设置（P1）

- 选择目标热点、采样间隔（1 秒默认，可选 2/5 秒）、开机自启开关、数据目录展示与打开、主题/透明度（可选）、显示"关于/统计口径说明"。

### FR-10 开机启动（P1）

- 通过当前用户启动项（注册表 Run 或启动文件夹）实现，**不需要管理员权限**，不写系统级服务。
- 用户可关闭；关闭后立即移除启动项。

### FR-11 单实例（P0）

- 重复启动时激活已有实例（悬浮窗置顶提示），不启动第二个采样器。

### FR-12 托盘图标（P1，待确认）

- 提供系统托盘图标作为备用入口（显示/隐藏悬浮窗、打开统计、退出）。
- 总指令未要求托盘图标，作为增强项在阶段 6 与用户确认后再做。

## 2. 非功能需求

| 编号 | 需求 | 衡量方式 |
| --- | --- | --- |
| NFR-01 稳定性 | 连续运行 72 小时不崩溃、不泄漏 GDI/句柄 | 阶段 7 长稳测试 + 任务管理器 |
| NFR-02 准确性 | 同会话与系统统计误差 ≤ 1 个采样间隔的量 | 对照 Windows 数据使用量 |
| NFR-03 性能 | 空闲 CPU < 1%，内存 < 80 MB | 性能计数器 |
| NFR-04 启动 | 冷启动到胶囊出现 < 2 秒 | 秒表 |
| NFR-05 可维护 | Core 无 UI/Win32 依赖，核心逻辑有单元测试 | 代码评审 + 覆盖率 |
| NFR-06 隐私 | 不联网、不上传任何数据 | 网络抓包/代码检查 |
| NFR-07 权限 | 普通用户权限即可运行 | 标准用户账户测试 |
| NFR-08 可移植 | 数据目录可迁移，卸载不残留系统改动 | 手动检查 |

## 3. 明确的排除项（不得实现）

- 运营商套餐余量查询、破解任何官方 App、短信自动读取。
- 将两个窗口合并、在悬浮窗内加入图表/日周月统计。
- 注入 Explorer、修改任务栏、替换系统组件。
- 按进程统计流量、驱动级抓包。
- 云同步、账号、遥测。

## 4. 待用户确认的问题（不阻塞阶段 0）

1. 短暂掉线（< 5 秒）是否合并为同一会话？当前按总指令"每次连接新建会话"。
2. 悬浮窗是否需要系统托盘图标作为备用入口（FR-12）？
3. 统计窗口的默认时间范围（今日 / 最近 7 天 / 本月）？
4. 是否需要"重置统计"功能？若需要，是删除全部历史还是按日期区间删除？
5. 采样间隔是否允许用户调整（影响精度与 CPU）？
