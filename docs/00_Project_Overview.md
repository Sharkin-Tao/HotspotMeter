# 00 项目概览

## 1. 背景

用笔记本连接手机 Wi-Fi 热点时，Windows 只告诉用户"已连接"，不显示这个热点已经消耗了多少流量。运营商按套餐计费，超额可能限速或额外扣费，而用户往往在收到短信时才意识到用量已经很大。

现有方案的问题：

- 手机端热点页面只显示手机自身统计，不覆盖电脑这块网卡的收发；
- 通用流量监控软件通常按"所有网卡总量"统计，会把学校 Wi-Fi、有线网、VPN 混在一起；
- 重型的桌面监控工具安装体积大、常驻内存高，与"只想看一个数字"的需求不匹配。

## 2. 产品定位

**一个常驻桌面的极简胶囊状态栏 + 一个按需打开的统计窗口。**

- 平时只占用任务栏旁一小块区域，显示"是否连着目标热点 / 本次会话已用流量 / 实时上下行速度"。
- 需要看日/周/月用量时，右键打开独立统计窗口。
- 原生 WPF + Win32 API，不做 Electron，不引入大型依赖。

## 3. 目标用户

- 主要：使用手机热点上网、流量套餐有限的 Windows 用户（本项目的第一位用户是软件技术专业大一学生）。
- 次要：需要粗略核查"这台电脑通过热点用了多少流量"的开发/测试人员。

## 4. 核心概念（三个统计口径，不可混淆）

| 口径 | 含义 | 使用位置 |
| --- | --- | --- |
| **当前会话流量** | 从"目标热点连接成功"到"断开"之间累计的网卡收发字节 | 悬浮状态栏 |
| **每日热点总流量** | 某本地自然日内，所有会话流量之和（含跨午夜拆分） | 统计窗口 |
| **历史累计统计** | 全部日期、全部会话的持久化记录与聚合 | 统计窗口 |

悬浮窗显示的是**当前会话**，不是今日、不是本月。这是已确认的产品设计。

## 5. 典型使用场景

1. **日常**：开机后程序自启，连上手机热点，胶囊变绿并显示流量与速度；断开后变红并保留上次会话数字，标注"上次会话"。
2. **月中检查**：右键 → 流量统计，看本月已用多少、哪几天用得最多。
3. **异常排查**：发现数字不动或速度异常，检查是否选错了热点、网卡是否被重建、程序是否被睡眠打断。
4. **换网络**：连上学校 Wi-Fi 时，胶囊保持红色（不是目标热点），不产生会话、不计流量。

## 6. 关键约束

- **准确性优先**：只统计目标热点对应网卡；不叠加 VPN/虚拟网卡；计数器回退、接口重建、睡眠唤醒都必须重新建基线。
- **稳定性优先**：不注入 Explorer、不修改系统文件；定位失败时退化为手动拖动，而不是强行 hack。
- **诚实**：网卡字节 ≠ 运营商计费；断电可能丢失最后一个检查点后的少量数据。这些都要写进界面说明与文档。
- **可维护**：分层清晰，Core 不依赖 UI 与 Win32，便于测试。

## 7. 非目标（第一版明确不做）

- 中国移动套餐余量获取（需要 Android 配套模块，后续单独立项；禁止破解官方 App）。
- 按进程/按应用的流量归因（需要 ETW 或驱动，超出轻量定位）。
- 多台电脑的云端汇总、账号体系、遥测上传。
- 路由器/其他设备的流量统计。
- 把悬浮窗嵌入 Windows 原生任务栏（公开 API 不支持，见 02）。

## 8. 成功标准

阶段 7 结束时，应同时满足：

1. 连上选定热点 10 秒内出现绿色胶囊，数字在 1–2 秒内开始变化；断开 5 秒内变红。
2. 与 Windows"设置 → 网络 → 数据使用量"中该网卡的数值相比，同会话误差在一次采样量级内（允许因采样时刻不同产生的差异）。
3. 人为制造 10 次断开/重连、3 次睡眠唤醒、1 次强制结束进程后，数据库无重复累计、无负数、无丢失超过一个检查点周期（约 10 秒）的异常。
4. 跨午夜会话在两天中各占正确比例（±1 个采样间隔）。
5. 统计窗口关闭后，悬浮窗与后台采样继续正常。
6. 常驻内存目标 < 80 MB，空闲 CPU 平均 < 1%（在主流 4 核以上机器上）。

## 9. 术语

| 术语 | 说明 |
| --- | --- |
| 目标热点 / Hotspot | 用户明确选定要监控的那个手机热点，用"接口 GUID + SSID + BSSID"共同标识 |
| 会话 / Session | 一次连续的"目标热点连接 → 断开"区间，每次连接新建一条记录 |
| 检查点 / Checkpoint | 把当前会话累计值写入数据库的动作，默认 5–10 秒一次 |
| 基线 / Baseline | 会话开始或重建采样时记录的系统计数器原始值，差值从这里起算 |
| 快照 / Snapshot | 采样间隔内产生的增量记录（见 04 数据模型） |
| 自然日 | 本地时区下的 00:00–24:00，跨日按采样时间归属 |
