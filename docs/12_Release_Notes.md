# 12 · 发布说明（Release Notes）

## HotspotMeter 0.1.0

- **版本**：0.1.0
- **发布状态**：候选发布（便携版）；安装包未制作
- **发布日期**：2026-11-15
- **目标平台**：Windows 10 1809+ / Windows 11，x64
- **发布模式**：self-contained，win-x64，文件夹发布（非单文件）

### 主要功能

- 悬浮胶囊：连接状态、本次会话流量、实时上/下行速度；圆角、可拖动、可固定、位置记忆。
- 任务栏适配：按任务栏高度自动选择尺寸/密度，可停靠在任务栏附近；前台/任务栏交互后恢复层级（受 Windows Shell band 限制）。
- 独立统计窗口：今日、最近 7 天、指定日期；下载/上传/总量；每日记录与连接次数/时长。
- 逐程序流量：Windows 网络归属 API；未归属流量单独列示，不做分摊。
- 系统托盘、设置窗口、开机自启、统计窗口任务栏显示开关。
- 中英双语：首次启动选择，设置/统计/胶囊/托盘即时切换。
- SQLite 本地历史；10 秒检查点、异常退出恢复、跨午夜拆分、日汇总。

### 本次发布包含的修复与改进

- 退出时监控释放改为线程池执行并记录超时，避免 UI 固定冻结 3 秒。
- 配置 `ui-state.json` 原子写入，损坏文件保留为 `.bad-*` 并记录日志。
- 数据库暂时占用（BUSY/LOCKED/IO）不再直接隔离；仅确定损坏时备份并重建。
- SQLite `synchronous=FULL`，与“异常断电最多丢失最后一个检查点”的承诺一致。
- 睡眠/挂起期间不再计入连接时长；目标热点断开当帧不计入。
- 检查点失败不再推进持久化基线，下一轮重算，避免静默丢字节。
- 启动清扫遗留会话标记为 Abandoned（映射状态 3）。
- 目标热点开机时尚未关联时，每 5 秒重试解析，不需要重启程序。
- 统计查询按当前热点 ProfileKey 过滤；加载版本守卫避免旧查询覆盖新界面。
- 统计窗口接入深色原生标题栏。
- 启动器/托盘/统计/胶囊在 Explorer 重启、窗口关闭后恢复。
- 全量中英文本地化；首次启动语言选择；旧配置无语言字段时进入选择流程。

### 系统要求

- Windows 10 1809（build 17763）及以上，或 Windows 11；x64。
- 自包含发布不要求预装 .NET Desktop Runtime。
- 源码构建需要 .NET 10 SDK。
- 正常使用不需要管理员权限。

### 安装

1. 解压 `HotspotMeter-win-x64.zip` 到有写权限的目录（例如 `%LOCALAPPDATA%\Programs\HotspotMeter`）。
2. 运行 `HotspotMeter.exe`。
3. 首次启动选择语言；之后可在设置中修改。

程序未签名，SmartScreen 可能提示。没有安装程序，不写入 Program Files、不注册系统服务、不创建计划任务。

### 数据位置与卸载

- 数据库：`%LOCALAPPDATA%\HotspotMeter\Database\hotspotmeter.db`
- 设置：`%LOCALAPPDATA%\HotspotMeter\ui-state.json`
- 日志：`%LOCALAPPDATA%\HotspotMeter\logs\`（诊断时）
- 卸载：托盘退出 → 如开启自启先在设置关闭 → 删除程序目录；如需清除历史，手动删除 `%LOCALAPPDATA%\HotspotMeter`。

### 已知限制

- 只统计选定热点对应的 Wi-Fi 网卡；VPN/虚拟网卡不计入。PC 侧字节数可能与运营商计费不同。
- 逐程序归属由 Windows 提供，可能缺失或滞后；未归属部分单独展示。
- Windows 11 展开的开始菜单/搜索、UAC 安全桌面、锁屏位于更高窗口 band；胶囊无法保证覆盖，关闭后恢复。
- 未签名；无安装程序；没有自动更新。
- 首次启动语言选择目前是模态窗口，取消即退出程序。
- 托盘菜单未做自动化展开验证（代码路径与文本已本地化）。
